# GitTrend

> 一个面向 GitHub 项目的趋势榜单与推荐系统 · A GitHub trending & recommendation system

[![status](https://img.shields.io/badge/status-WIP-yellow)](.)

## 简介

GitTrend 用于发现和推荐 GitHub 上的优质项目，核心围绕**榜单趋势**与**个性化推荐**两条主线：

- 汇总每日 / 每周的热门仓库，形成可浏览的榜单
- 结合语言、主题、Star 增速等维度，推荐你可能感兴趣的项目

## 计划功能

- [ ] 每日 / 每周趋势榜单（按 Star 增量排序）
- [ ] 按语言、主题、类型分类的榜单
- [ ] 个性化推荐（基于浏览与收藏行为）
- [ ] 项目详情页与关键指标趋势图
- [ ] 收藏、搜索与订阅
